# TamaGrid v0.5.0 Public Preview

TamaGridは、最大4つのCodex App Server taskを1画面で実行・監視するlocal-first desktop cockpitです。

## Highlights

- 2列、2×2、横4列、縦4段layoutとPane並べ替え
- 保存済みCodex threadの検索、展開、resume、chat名編集
- streaming timeline、最新行auto-scroll、Stop、Steer、approval
- 動的model / reasoning optionとCodex残り使用量
- English初期表示とEN / JP切替、4 theme、85%〜200%の文字サイズ
- 終了時のウィンドウ位置・サイズ・最大化・全画面状態の復元
- Codex標準code reviewと安全なPull Request準備
- method別typed Rust IPC、native executable picker、dangerous turnのnative確認
- command / cwd / file changesを確認できるapproval cardとprocess-tree containment

## Windows artifacts

- `TamaGrid_0.5.0_x64-setup.exe` — 通常の対話型installer
- `TamaGrid_0.5.0_x64_en-US.msi` — MSIが必要な環境向け

両方ともAuthenticode未署名です。Microsoft Defender SmartScreenが警告する場合があります。SmartScreenを無効化せず、GitHub Releaseの配布元と `SHA256SUMS.txt` を確認し、信頼できる場合だけ実行してください。

```powershell
Get-FileHash -LiteralPath .\TamaGrid_0.5.0_x64-setup.exe -Algorithm SHA256
Get-AuthenticodeSignature -LiteralPath .\TamaGrid_0.5.0_x64-setup.exe
```

tagged releaseはGitHub Artifact Attestationも生成します。

```powershell
gh attestation verify .\TamaGrid_0.5.0_x64-setup.exe --repo tamas-hub/tamagrid
```

attestationはGitHub Actionsのbuild provenanceを示しますが、Authenticode署名の代替ではありません。

Releaseには `THIRD_PARTY_NOTICES.md` とproduction JavaScript dependencyのCycloneDX SBOM (`tamagrid-js.cdx.json`) も含まれ、どちらも `SHA256SUMS.txt` の検証対象です。

## Requirements

- Windows 10 / 11
- Microsoft Edge WebView2
- user-installed OpenAI Codex CLI with a compatible stable App Server API
- an existing Codex sign-in when the selected workflow requires it

TamaGridはCodex binary、model、ChatGPT credentialを同梱しません。

## Known limitations

- Windows Authenticode署名なし
- macOS Developer ID署名 / notarizationなし
- macOSはApple Silicon / IntelともGitHub Actionsでbuildしていますが、native実機での起動・履歴resume・approval・終了確認は未実施
- stdio transportのみ
- commit、push、Pull Request作成は自動実行しない
- Codex App Server更新により互換性調整が必要になる場合がある
