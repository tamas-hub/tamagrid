# TamaGrid v0.7.0 Public Preview

`v0.7.0`は、複数Paneへの履歴resume、3-column layout、Pane session管理とmacOSの強制終了時process回収を追加したPublic Previewです。

## Highlights

- Historyからresumeする宛先を表示中の任意Paneから選択可能
- App Serverのthread start / resumeを直列化し、大きな履歴の復元待ちを90秒へ拡張
- 2 / 3 / 4 Pane layoutと、Pane単位のsession clear
- 空Paneの`+`から新しいsessionを開始
- composer末尾を1行へ圧縮し、send操作をpaper-plane iconへ更新
- 200%文字表示と狭い4-column Pane向けのresponsive control省略
- macOSでTamaGrid本体が強制終了してもApp Server process groupを回収する独立`kqueue` guard

## Windows artifacts

- `TamaGrid_0.7.0_x64-setup.exe` — 通常の対話型installer
- `TamaGrid_0.7.0_x64_en-US.msi` — MSIが必要な環境向け

両方ともAuthenticode未署名です。Microsoft Defender SmartScreenが警告する場合があります。SmartScreenを無効化せず、GitHub Releaseの配布元と`SHA256SUMS.txt`を確認し、信頼できる場合だけ実行してください。

## Validation status

- frontend lint、TypeScript production build、51 frontend tests、15 Rust testsがWindowsで成功
- Windows packaged Tauri / WebViewで3分間、9,000 delta・2,304,000 bytesを流し、sequence gap 0、最大frame gap 33 ms、最新行追従距離0 pxで完走
- 同じpackaged testの強制終了後、productionと同じJob Object内のfixture親・孫processを642 msで回収、残留0
- macOS Apple Silicon / Intelのnative Bundle smokeで1,500 delta・384,000 bytesを欠落なく処理
- packaged app強制終了後、macOSのfixture親・孫・guardをApple Silicon 2,794 ms、Intel 996 msで回収し、残留0
- test-only command、helper、環境変数はnon-default featureへ隔離し、配布buildには含めない

## Requirements

- Windows 10 / 11 + Microsoft Edge WebView2、またはmacOS 10.15以降
- compatible stable App Server APIを持つuser-installed OpenAI Codex CLI
- 選択したworkflowで必要となる既存のCodex sign-in

TamaGridはCodex binary、model、ChatGPT credentialを同梱しません。

## Known limitations

- Windows Authenticode署名なし
- macOS Developer ID署名 / notarizationなし
- stdio transportのみ
- commit、push、remote branch、Pull Request作成は自動実行しない
- Codex App Server更新により互換性調整が必要になる場合がある
