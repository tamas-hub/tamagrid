# TamaGrid v0.6.0 Public Preview

`v0.6.0`は、TamaGridのcompact UI、streaming queue、process containment、release validationを強化したPublic Previewです。

## Highlights

- TamaGrid、接続状態、残り使用量、History、主要操作、window controlsを1行にまとめたnative command rail
- 90%〜200%を10%刻みで変更できる文字サイズと、EN / JPを含むcompact status rail
- 初期3行・最大10行へ自動拡張し、model・reasoning controlsを下段へ整理したcompact composer
- 実行対象Codex CLIのstable App Server JSON Schemaとの互換性検査
- Rust / rendererのbounded・coalesced streaming queueと100,000-delta stress test
- 実際のpackaged Tauri window、WebView、Rust Channelを通る隔離型soak test
- Windows Job Object descendant終了testとnative macOS向けUnix process-group test
- Windows x64、macOS Apple Silicon、macOS IntelのBundle smokeへ30秒のpackaged WebView gate
- GitHub repositoryの独自social-preview画像と公開・privacy文書の追加hardening

## Windows artifacts

- `TamaGrid_0.6.0_x64-setup.exe` — 通常の対話型installer
- `TamaGrid_0.6.0_x64_en-US.msi` — MSIが必要な環境向け

両方ともAuthenticode未署名です。Microsoft Defender SmartScreenが警告する場合があります。SmartScreenを無効化せず、GitHub Releaseの配布元と`SHA256SUMS.txt`を確認し、信頼できる場合だけ実行してください。

## Validation status

- Windows packaged Tauri / WebView: 3分間、9,000 delta、2,304,000 bytes、sequence gap 0
- 最大animation-frame gap 50 ms、最新行追従距離0 px
- 正常終了後のTamaGrid / direct WebView child / test temporary directory残留0
- testは隔離identifierで動作し、Codex process、account、会話、credential、利用枠へ接続しない
- Windows x64、macOS arm64、macOS x64のBundle smokeで30秒のpackaged Tauri / WebView Channel gateとbundle生成が成功
- repository ownerから2026-08-14にmacOS実機で問題なしとのPass報告

## Requirements

- Windows 10 / 11 + Microsoft Edge WebView2、またはmacOS 10.15以降
- compatible stable App Server APIを持つuser-installed OpenAI Codex CLI
- 選択したworkflowで必要となる既存のCodex sign-in

TamaGridはCodex binary、model、ChatGPT credentialを同梱しません。

## Known limitations

- Windows Authenticode署名なし
- macOS Developer ID署名 / notarizationなし
- macOS実機Pass報告のpackage hash、機種、OS version、項目別結果は未記録
- packaged app強制crash時のprocess-tree回収は未確認
- stdio transportのみ
- commit、push、remote branch、Pull Request作成は自動実行しない
- Codex App Server更新により互換性調整が必要になる場合がある
